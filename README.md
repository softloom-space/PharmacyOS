# PharmacyOS

Windows point-of-sale for pharmacies. Fast keyboard dispensing, batch and
expiry tracking, and it works without internet.

By [Softloom](https://softloom.space) · [Product page](https://softloom.space/products/cashier/pharmacyos/)

## Download

Get the latest installer from [Releases](../../releases/latest):

- **PharmacyOS-Setup.exe** — installs the app
- **PharmacyOS-Portable.exe** — runs without installing

Windows 10 or 11, 64-bit. The installer is not code-signed, so SmartScreen may
warn on first run — choose **More info → Run anyway**.
